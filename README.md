# ИИ-системы для бизнеса

Новый самостоятельный проект по AI_BUSINESS_SITE_HANDOFF от 5 сентября 2026 года.

## Статус

Идёт реализация. Это не публичный коммерческий релиз. Рабочее имя: «Новый бренд».

## Принятые ограничения

- Не изменять sharprod.com и другие репозитории.
- Не подключать платные API, платежи или рассылки без ключей и согласованных лимитов.
- Не выдумывать кейсы, контакты, статистику, авторов и результаты тестов.
- Не переиспользовать клиентские сканы для обучения, исследований или чужих отчётов.
- Статьи считать по реальным файлам и статусам, а не по редакционному плану.

## Архитектура реализации

Одно Python-приложение: серверный HTML, SQLite, файловый журнал и ограниченный сканер. Статический экспорт служит отдельным безопасным предпросмотром. В статическом предпросмотре серверные операции явно отключены.

Исходники, инструкция запуска, тесты и проверенный статус будут сохранены в этом репозитории в ходе реализации.
