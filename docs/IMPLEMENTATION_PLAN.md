# План реализации, 5 сентября 2026

Основание: согласованный AI_BUSINESS_SITE_HANDOFF. Стратегическое интервью не повторяется.

1. Проверить сохранение GitHub, доступные библиотеки, браузер и исходящие соединения. Первый README уже сохранён.
2. Собрать автономное ASGI-приложение: FastAPI, Jinja, SQLite, файловые статьи. Публичный HTML без зависимости от JavaScript.
3. Создать адаптивную визуальную систему, главную и 5 услуг, методику, цены, прозрачные состояния интеграций, журнал и бриф.
4. Реализовать ограниченный серверный сканер: проверка публичных адресов и DNS на каждом переходе, закрепление IP, robots, лимиты, частичный результат. Не включать публично без сетевого ограничения egress.
5. Реализовать приватность отчётов, сессии, CSRF, очередь SQLite, удаление, одноразовые ссылки с SMTP-адаптером. Проверить раздельный доступ.
6. Написать статьи отдельными содержательными текстами по реестру. Отдельно считать написанные, автоматически проверенные, прошедшие редакционную проверку и опубликованные.
7. Проверить исходники и браузерные сценарии. Создать переносимый HTML-предпросмотр с отключёнными серверными действиями, архив исходников и протокол тестов.
8. Сохранить проверяемые версии на GitHub. Публичный коммерческий запуск заблокирован до имени, контактов, документов и подключений.

## Границы среды

Python 3.13, FastAPI 0.128.2, Starlette 0.50.0, Jinja 3.1.6, SQLite, urllib3 2.7.0, dnspython 2.8.0, mistune 3.2.1, Chromium и Playwright доступны. Flask не установлен, поэтому приложение использует доступный FastAPI. SMTP, платёжные, поисковые и LLM-ключи не предоставлены. Исходящая сеть проверяется отдельно; ошибка сети никогда не трактуется как ошибка проверяемого сайта.
